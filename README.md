# Surfside — E-Commerce Website

E-commerce website built with **Laravel**, featuring a product catalog,
shopping cart, and checkout flow.

## Features

- 🛍️ Product catalog with categories
- 🛒 Shopping cart
- 💳 Checkout flow
- 🔐 Authentication & user accounts
- 📱 Responsive design

## Tech Stack

- **Backend:** Laravel (PHP)
- **Database:** MySQL
- **Frontend:** Blade, Bootstrap / Tailwind CSS

## Getting Started

```bash
# Install dependencies
composer install
npm install

# Configure environment
cp .env.example .env
php artisan key:generate

# Run migrations
php artisan migrate

# Start the server
php artisan serve
npm run dev
```
